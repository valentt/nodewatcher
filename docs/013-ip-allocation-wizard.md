# Feature Ticket #013: IP Allocation Wizard

**Type:** Feature Request
**Priority:** High
**Status:** Proposed
**Created:** 2024-12-14

---

## Summary

Step-by-step wizard for IP address allocation with two modes:
1. **Simple Mode** - Select region, get automatic IP based on postal code
2. **Advanced Mode** - Manual subnet selection without region constraints

---

### Validation Rules

```python
def validate_subnet_request(subnet, user, pool):
    errors = []

    # Check subnet is within pool
    if not subnet.subnet_of(pool.network):
        errors.append("Subnet nije unutar odabranog poola")

    # Check subnet is available
    if is_subnet_allocated(subnet):
        errors.append("Subnet je već zauzet")

    # Check subnet doesn't overlap
    overlaps = find_overlapping_allocations(subnet)
    if overlaps:
        errors.append(f"Subnet se preklapa s: {overlaps}")

    # Check prefix size limits
    if subnet.prefixlen < 24:
        errors.append("Maksimalna veličina je /24")

    if subnet.prefixlen > 30:
        errors.append("Minimalna veličina je /30")

    return errors
```
